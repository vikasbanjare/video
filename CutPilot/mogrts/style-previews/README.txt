Drop REAL renders of caption styles here (or into ~/Documents/Pulse/style-previews/,
which survives reinstalls) and the gallery tile plays YOUR render instead of the
drawn preview.

  · Formats: .mp4  .mov  .gif  .png  .jpg  .webp
  · Name the file like the style — case/spacing don't matter:
        Bold Pop.mp4      bold-pop.gif      hormozi.png
  · A file in ~/Documents/Pulse/style-previews/ overrides one shipped here.

Send your renders to the developer and they get baked into the installer, so
every install ships real-render previews.
