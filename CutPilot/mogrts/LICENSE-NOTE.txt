CutPilot — bundled .mogrt templates
===================================

The .mogrt files in this folder are loaded automatically and shown in the
Templates gallery as editable caption/title templates (they ride the MOGRT
pipeline, so the words stay editable in Premiere — they are NOT burned-in PNGs).

HOW TO ADD / REMOVE TEMPLATES
-----------------------------
1. Drop a .mogrt file into this folder.
2. Add an entry to index.json:
     { "file": "MyTemplate.mogrt", "name": "My Template", "category": "Subtitles", "kind": "caption" }
3. Restart the panel. That's it — no code changes.

To remove one, delete the file and its index.json entry.
