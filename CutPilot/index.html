✏️ Review & edit the words

Fix a wrong word, delete a junk line (✕), merge into the line above (⤴), or add a missing line (＋). A ⚠️ banner marks any stretch the transcriber skipped — tap ＋ Add missing line there and type what was said.

✏️ Editable cards (🎬) drop captions you edit right inside Premiere's Essential Graphics — font, colour, size, position — exactly like native Premiere. Plain style cards are burned-in (baked into the picture). Add your own template packs in Settings → Template folders.
